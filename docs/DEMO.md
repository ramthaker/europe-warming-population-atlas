# Demo outline (target: 2 minutes 30 seconds)

1. **0:00–0:20 — Set the question.** “Where do projected temperature changes overlap with where people live?” Explain that the map shows scenarios, not predictions.
2. **0:20–0:55 — Explore the baseline comparison.** Show the 1981–2000 reference and the 2041–2060 period under RCP4.5. Pan across Northern, Central, and Southern Europe.
3. **0:55–1:25 — Compare pathways and time periods.** Switch to RCP8.5, then 2081–2100. Call out that colors represent annual mean change, not daily extremes.
4. **1:25–1:55 — Add the people layer.** Toggle 2020 population and click a cell. Explain the cell-level ensemble median, 10th–90th percentile range, and aggregated population estimate.
5. **1:55–2:20 — Explain the data path.** Name EURO-CORDEX, GHSL, Amazon Location Service, S3, and CloudFront. Point viewers to the README for attribution and processing steps.
6. **2:20–2:30 — Close.** Share the live URL and public source repository if available.
